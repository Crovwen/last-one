# چک‌لیست تست دستی LAST ONE

> کد روی دیتابیس و تلگرام واقعی اجرا نشده بود (فقط تست‌های منطق و بررسی ایستا انجام شده). اگر جایی خطا دیدی، متن لاگ رندر یا پیام خطا را بفرست تا درست شود.
> برای تست نبرد دو حساب تلگرام لازم داری (A و B) و یک گروه که ربات داخلش باشد.

## ۰) راه‌اندازی
1. استقرار در رندر و دیدن `LAST ONE started` در لاگ. اگر خطای مهاجرت دیدی، متنش را بفرست.
2. `/admin` (با حساب ادمین) پنل را نشان بدهد. `/content items` فهرست آیتم‌ها را نشان بدهد (محتوا خودکار ساخته می‌شود).

## ۱) فاز ۱ و ۲ — حساب و شخصیت
- `/start` ← نام شخصیت ← منوی اصلی. نام تکراری رد شود.
- «شخصیت»: سلامتی/سیری/تشنگی/انرژی/خستگی و ۱۰ مهارت دیده شود.
- «کوله‌پشتی»: چاقو (پوشیده)، ۳ نان، ۳ آب. روی نان بزن ← مصرف. وزن/ظرفیت دیده شود.
- حالت رفتار (تنظیمات): محتاط/عادی/سریع.
- ری‌استارت دستی سرویس رندر (Manual Deploy) ← همه چیز سر جایش باشد.

## ۳) جنگل
- «جنگل» ← «جمع‌آوری چوب» ← بعد از ~۵ دقیقه پیام نتیجه برسد (حتی اگر ربات را نبینی). چوب در کوله باشد.
- «استراحت» ۱ ساعت ← «استراحت سریع» با سکه.
- «مأموریت» ← دریافت ← انجام.

## ۶ تا ۸ — خانه، حیوان، نیرو
- «خانه» ← «ساخت و ارتقا» ← با `/giveitem نام wood 50` و `/give نام 300` مواد بده ← خانه چوبی/محل نگهبان/محل حیوانات بساز.
- «حیوانات» ← خرید سگ ← وظیفه «نگهبان خانه» ← غذا ← تمرین.
- «مارکت» ← «استخدام نیرو» ← نگهبان ← استقرار «نگهبان ورودی» ← تجهیز شمشیر از انبار (باید از انبار خودت خارج شود).

## ۴ و ۵ — نبرد (دو حساب)
- B در خانه است (`/give` برای B بده تا محافظت تازه‌وارد نداشته باشد: `/set newbie.protection_hours 0` قبل از ساخت B یا ۲۴ ساعت صبر).
- در گروه، روی پیام B ریپلای کن و بنویس: **حمله**. گزارش شناسایی بیاید ← «تأیید» ← نوع حمله ← «ادامه حمله».
- B در گروه «ورود مدافع» را بزند. دکمه «فرار» را امتحان کن.
- بعد از پایان: «برداشت غنیمت» / «غارت مرحله‌ای». بعد از شکست: اسارت یا مرگ.
- اسارت: از منوی «اسرای من» باج/کار آزادی/مصادره را تست کن؛ اسیر باج را بپردازد.
- مرگ: «بازگشت سریع»، سپس «رفتن به محل مرگ».

## ۹ — قبیله
- A: تأسیس قبیله (۵۰۰ سکه). B: درخواست/پیوستن. نقش‌ها، قفل‌کردن، خزانه (واریز/برداشت)، اهدا و امانت‌گذاری آیتم، ساخت برج.

## ۱۰ — اقتصاد
- فروشگاه، فروش به بازار سیستمی، ساخت وسایل، آگهی بازار بازیکنان و خرید با حساب دوم، انتقال سکه (سکه‌های اولیه قفل‌اند)، معامله امن دوطرفه.

## ۱۱ — رویداد و مدیریت
- در گروه: `/setgroup` سپس `/event cargo` و `/event beast`.
- `/season_new فصل_اول 0 7 0 100,50` ← در «گزارش‌ها ← فصل» ثبت‌نام کن.
- `/edit items sword power 20`، `/disable items sword` (بازیکنانی که شمشیر دارند آسیب نمی‌بینند)، `/tx نام`، `/reports`.

## ۱۲ — پایداری
- `/backup` فایل بفرستد. سرویس را ری‌استارت کن ← نبرد نیمه‌کاره/فعالیت/اسارت ادامه پیدا کند.
