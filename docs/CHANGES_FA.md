# تغییرات این به‌روزرسانی

**منو و دستورها**
- همه منوها هم در چت خصوصی و هم داخل گروه باز می‌شوند؛ منوی هر نفر فقط برای خودش کار می‌کند.
- برای هر بخش یک کلمه: جنگل، جستجو، کوله، انبار، خانه، حیوانات، خرید حیوان، نیروها، استخدام، قبیله، مارکت، معامله، گزارش، اسارت، تنظیمات، راهنما و ...
- دستورهای اسلشی: /menu /help /forest /inv /home /profile
- منوی «راهنما» با راهنمای هر بخش و «لیست دستورات».
- دکمه‌ها رنگی‌اند: آبی (عادی)، سبز (تأیید/پذیرش)، قرمز (لغو/رد). برای دیدن رنگ‌ها تلگرام باید به‌روز باشد.

**گروگانگیری و حمله**
- گروگانگیری برای همه: روی هدف (بیرون از خانه) ریپلای کن و بنویس «گروگانگیری با @نفر۲ @نفر۳» (۲ تا ۴ نفر). هم‌دستان باید تأیید یا رد کنند؛ پیام ربات مرحله‌به‌مرحله ویرایش می‌شود. هرچه هدف همراه دارد بین اعضا تقسیم می‌شود.
- حمله به خانه: «حمله به خانه» یا «حمله به خانه با @نفر۲ ...» (تا ۵ نفر). مراحل: رسیدن به خانه و تله‌ها ← تصمیم صاحب‌خانه (دفاع/تسلیم؛ ۵ دقیقه بی‌پاسخی = خواب) ← تصمیم هر مهاجم درباره نگهبان (مبارزه/دور زدن) ← نبرد ← ۵ دقیقه غارت محدود.
- «حمله» ساده فقط برای کسی است که بیرون از خانه است.
- خفتگیری: ریپلای + «خفتگیری»؛ مقدار کمی سکه (متناسب با ثروت قربانی)، فاصله ۱۰ دقیقه برای هر نفر.

**محافظ تازه‌وارد:** ۶ ساعت؛ با «محافظ روشن / محافظ خاموش» یا از تنظیمات قابل‌کنترل است.

**پنل ادمین:** فقط `/admin` (یا «پنل») ← همه‌چیز دکمه‌ای: آمار، تنظیمات بازی، محتوا، کاربران، گزارش تخلف، فصل، رویداد/گروه‌ها، پشتیبان. داخل گروه `/admin` ابزار ثبت گروه و رویداد را می‌دهد.

**سرعت:** کمتر پرس‌وجو در هر پیام، کش دستورهای دیتابیس، تلاش دوباره هنگام قطع اتصال. برای بیشترین سرعت، ناحیه (Region) دیتابیس Neon را هم‌ناحیه سرویس رندر انتخاب کن (مثلاً هر دو Frankfurt).
