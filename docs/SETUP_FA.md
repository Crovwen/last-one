# راه‌اندازی رایگان LAST ONE (قدم‌به‌قدم)

## ۱) دیتابیس رایگان (Neon)
1. در neon.tech با ایمیل یا گیت‌هاب ثبت‌نام کن و یک Project بساز.
2. وارد Connect شو، گزینه **Connection pooling را خاموش** کن و رشته‌ای که با `postgresql://` شروع می‌شود را کپی کن. این مقدار `DATABASE_URL` است.
3. محدودیت‌های پلن رایگان Neon را همان‌جا یک بار بخوان؛ این‌ها ممکن است عوض شده باشند.

## ۲) توکن ربات
از @BotFather توکن بگیر (`BOT_TOKEN`). آیدی عددی خودت را هم از ربات‌هایی مثل @userinfobot بگیر (`ADMIN_IDS`).

## ۳) کد را روی گیت‌هاب بگذار
یک مخزن (repo) خصوصی بساز و همه فایل‌های این پروژه را داخلش آپلود کن (پوشه‌ها `app`، `migrations`، `tests`، `docs` و فایل‌های `requirements.txt`، `render.yaml`).

## ۴) ساخت سرویس در رندر
1. New ← Web Service ← مخزن را انتخاب کن، Instance Type = **Free**.
2. Build Command: `pip install -r requirements.txt`
3. Start Command: `python -m app.main`
4. در Environment این سه مقدار را اضافه کن: `BOT_TOKEN`، `DATABASE_URL`، `ADMIN_IDS`.
5. Deploy کن. بعد از چند دقیقه در لاگ باید `LAST ONE started` را ببینی. در تلگرام به ربات `/start` بزن.

## ۵) جلوگیری از خواب سرویس
رندر سرویس رایگان را بعد از ۱۵ دقیقه بی‌کاری می‌خواباند. در uptimerobot.com یک مانیتور HTTP بساز که هر ۵ دقیقه آدرس `https://اسم-سرویس.onrender.com/health` را باز کند.
این آدرس به دیتابیس وصل نمی‌شود، پس دیتابیس می‌تواند بخوابد و منابعش مصرف نشود.

## نکته مهم: ساعت‌های رایگان رندر
ساعت رایگان ماهانه رندر بین همه سرویس‌های رایگان یک اکانت مشترک است. اگر ربات دیگری هم روی همین اکانت داری، هر دو را نمی‌شود ۲۴ ساعته روشن نگه داشت.

## پشتیبان
هر ۲۴ ساعت یک فایل پشتیبان به پیوی ادمین‌ها فرستاده می‌شود و با `/backup` هم می‌توانی همان لحظه بگیری. این فایل را جای امنی نگه دار.
## دستورهای ادمین
`/admin` — `/settings` — `/set کلید مقدار` (مثلاً `/set economy.start_coins 150`) — `/backup`

## بعد از اولین اجرا
- محتوای بازی (آیتم‌ها، فعالیت‌ها، ساختمان‌ها، نژادها، نیروها، مأموریت‌ها) خودکار ساخته می‌شود.
- برای رویدادهای گروهی: ربات را به گروه اضافه کن و داخل گروه `/setgroup` بزن.
- برای ریپلای «حمله» در گروه، در BotFather گزینه Group Privacy را خاموش کن (Bot Settings ← Group Privacy ← Turn off) تا ربات پیام‌های گروه را ببیند.
- تست دستی: `docs/TEST_CHECKLIST_FA.md`

## برای سرعت بیشتر
- در Neon و Render **یک ناحیه (Region) یکسان** انتخاب کن (مثلاً هر دو Frankfurt). فاصله زیاد بین دیتابیس و سرور بزرگ‌ترین دلیل کندی است.
- رشته اتصال Neon را **بدون pooler** (Connection pooling خاموش) بگذار.
- سرویس رایگان رندر بعد از ۱۵ دقیقه می‌خوابد و بیدارشدنش حدود یک دقیقه طول می‌کشد؛ پینگر UptimeRobot این را حل می‌کند.

## به‌روزرسانی روی رندر (Termux)
داخل پوشه پروژه فایل‌های جدید را جایگزین کن، بعد:
```
git add .
git commit -m "update"
git push
```
رندر خودش دوباره دیپلوی می‌کند و تغییرات دیتابیس (migration) را خودکار اعمال می‌کند.
